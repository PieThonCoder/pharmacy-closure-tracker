About this board's data

  • Illinois (IDFPR via data.illinois.gov) is unusual: the file retains closed and lapsed licenses with a terminal status, so closures show up here as status changes rather than removals. Controlled-substance registrations are a second license per site and are excluded.

Primary source

  • Illinois IDFPR via data.illinois.gov (weekly; retains lapsed licenses)

Method, caveats and the meaning of each event type: tracker method. Removal from a roster is not proof of closure.
