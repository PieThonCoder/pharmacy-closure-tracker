About this board's data

  • Nevada's Board of Pharmacy facility report (the tracker keeps Type = Pharmacy) carries status, license date and street address and retains terminal statuses (Closed / Non Renewed / Expired / Voluntary Surrender / Revoked), so closures should appear as status changes - not yet observed, since recording began 2026-08-16. The majority of pharmacy rows are out-of-state (nonresident) licensees; they are flagged by address state and excluded from the in-state counts.

Primary source

  • Nevada State Board of Pharmacy - facility license report (weekly; recorded from 2026-08-16)
