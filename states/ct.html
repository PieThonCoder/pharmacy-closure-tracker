About this board's data

  • Connecticut (DCP via data.ct.gov) publishes two rosters, in-state and nonresident. The export lists licenses already renewed for the coming September-1 term, so in July-August established pharmacies re-enter the file as they renew; those are classed as renewal re-listings, not openings.

Primary source

  • Connecticut DCP - in-state pharmacies via data.ct.gov (weekly)
  • Connecticut DCP - nonresident pharmacies via data.ct.gov (weekly)

Method, caveats and the meaning of each event type: tracker method. Removal from a roster is not proof of closure.
