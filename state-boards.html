What each state pharmacy board publishes about pharmacy licenses

A 51-jurisdiction scorecard of the public roster each board of pharmacy exposes for pharmacy sites (not pharmacists): is there a downloadable file, does it carry a status and an issue date, does the board publish a dated closure, and does a closed license stay in the file or vanish. Surveyed 2026-08-16.

Why this matters. Whether a pharmacy closure can be seen at all - and when - depends on what the board publishes. Only 4 of 51 jurisdictions publish a dated closure event in their public data (MA, MS, NY, OK (lookup portal only); IL partially; KS shows one on a lookup template that scripted requests cannot reach). In 10 the public data carries active licenses only, so a license that closes simply leaves the file - observed directly in AK, CA, MI, NH, RI, WV, inferred for DC, ND, NE, OR which publish no status field at all; 3 keep only a short tail of terminal statuses (HI, TX, UT); 18 retain closed licenses with a terminal status. A license can also leave a roster through lapse, change of ownership (re-licensing under a new number) or a data correction, so a removal is a signal, not a closure. Everywhere a dated closure is not published, the closure date can only come from comparing successive snapshots of the roster - which is what this tracker does.

Method

Each jurisdiction was checked by two independent passes on 2026-08-16: the first fetched the board's site, file or lookup portal live and filled every column; the second re-fetched independently and tried to refute each field. 28 of 51 records were confirmed as written; 23 were corrected on the second pass (the corrected values are shown). The passes' raw evidence quotes sample roster rows and is kept in the private survey record; the public JSON carries the structured fields and notes. Read-only: no logins, no accounts, no CAPTCHA solving, robots.txt respected; person rosters (pharmacists, technicians) were out of scope. "Bulk file" means a free, directly downloadable, machine-readable file or open API of pharmacy sites; "PDF only" means a free roster that needs PDF text extraction; "paid" means the board sells the list; "bot-blocked" means a public file exists but a scripted request is refused; "stale" means the file is no longer updated. Every judgement below carries its evidence in the expandable notes; unknowns are marked "?" rather than guessed. The underlying JSON is published: state-boards-scorecard.json (CC BY 4.0).

What the survey shows

  • Bulk availability: 20 boards publish a free machine-readable file or open API; 3 publish a PDF roster; 9 sell the list; 5 have a public file that refuses scripted requests; 1 has a file that stopped updating; 13 offer per-record lookup only.
  • Dated closures are rare: MA, MS, NY, OK (lookup portal only) publish one; IL partially; KS unreachable to scripts. Every other board leaves the closure date to be inferred from successive snapshots.
  • Active-only publication is common: in 10 jurisdictions the public data carries active licenses only (6 observed, 4 inferred from the absence of any status field), so removal is the only public trace when a license ends; 3 more keep only a short tail of terminal statuses.
  • Archived prior rosters are essentially unavailable: 39 boards confirmed "no", 11 unknown, and the single "yes" (NH) was not verified as an archive series on the second pass - treat it as unconfirmed.
  • Nonresident (mail-order / out-of-state) pharmacies are mixed into the same file in 31 jurisdictions, kept in a separate file in 4, absent in 6.
  • Coverage of this tracker: 16 jurisdictions recorded and published today, plus NE, OR recorded as raw PDF rosters (parsers pending); 5 more have a free file or PDF roster and are candidates for addition (AK, MI, ND, NY, VT) - subject to fetch and format tests (some are frozen files, some refuse scripted requests, one needs a browser session).
